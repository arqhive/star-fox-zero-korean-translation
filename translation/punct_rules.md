# 구두점·문체 검수 기준 (2차 교정)

원문 일본어는 대사에 마침표(。)를 쓰지 않고 쉼표 대신 공백을 쓴다. 1차 번역이 이를 그대로 따라가서
한국어 표기법에 맞지 않는다. 아래 기준으로 전면 교정한다.

## 1. 마침표
- **평서문은 마침표로 끝낸다.** 예: `지상에 적 확인` → `지상에 적 확인.`(X) … 아래 예외 참고
- 다만 **무전 호출·상황 보고처럼 명사로 끝나는 짧은 구**는 마침표를 찍지 않는다.
  예: `적 미사일 접근`, `그레이트폭스 이상 없음`, `거리 50`
- `!`, `?`, `...`로 끝나면 마침표를 덧붙이지 않는다.
- **여러 줄(\n)일 때는 마지막 줄에만** 마침표를 찍는다. 중간 줄은 문장이 이어지면 아무것도 찍지 않고,
  문장이 끝났으면 마침표를 찍는다.
- 다음은 마침표를 찍지 않는다(문장이 아님):
  - 메뉴 항목·버튼·라벨: `게임 계속하기`, `트레이닝`, `스코어 리스트`, `{I3}\n출격`
  - 고유명사·인물명·스테이지명·기체명: `폭스 맥클라우드`, `행성 코네리아`, `아윙 FX`
  - 결과 배너·표제: `작전 완료`, `베스트 스코어`, `미션 기록`
  - 한 단어 감탄사: `발사!!!`, `크윽`
- 확인 문구·안내문은 마침표를 찍는다: `저장하지 않은 내용은 사라집니다.`

## 2. 쉼표
- **호격(부르는 말) 뒤에는 쉼표.** `폭스 뒤를 조심해` → `폭스, 뒤를 조심해`
  - 문장 끝에 이름이 올 때도 쉼표: `잘했다, 폭스`
  - 이름이 그 자체로 외침이면 쉼표 없이 느낌표: `폭스!!!`
- **감탄사·응답 뒤 쉼표**: `훗, 소문만 못하군요`, `아뇨, 저희에겐`, `자, 간다`
- **원문이 공백으로 끊은 자리**가 한국어에서 절 경계면 쉼표로 바꾼다.
  `전 기체 목표는 콜로니 안이다` → `전 기체, 목표는 콜로니 안이다`
- 나열에는 쉼표: `실드, 연료 모두 정상이다`
- 남용 금지: 짧은 문장 안에서 두 번 이상 찍지 않는다. 주어 뒤에 습관적으로 찍지 않는다.

## 3. 일본어 직역투 교정
아래는 뜻을 바꾸지 말고 자연스러운 한국어 구어로 다듬는다.
- `~하는 것이다`, `~라는 것이다` → `~한다`, `~인 거다`
- `~해 두는 게 좋다`가 어색하면 `~해 둬`, `~하는 게 좋겠어`
- `~에 있어서`, `~에 대해서` 남용 → `~에서`, `~은`
- 이중 피동(`~되어지다`), 과한 피동 → 능동
- `~해 주마`, `~해 주지`의 반복 → 상황에 맞게 `~하겠다`, `~할게`
- `그 녀석`, `저 녀석`의 반복 → 문맥에 따라 `놈`, `저놈`, 생략
- 일본식 관용구 직역 확인: `気を抜くな`는 `방심 마라`(자연스러움), `腕をあげたな`는 `실력이 늘었군`
- 무전 대사는 **짧고 입에 붙게**. 문어체(`~하였다`, `~하도록 한다`)는 쓰지 않는다.

## 4. 바꾸면 안 되는 것
- 캐릭터 말투와 고유명사는 `work/glossary.md` 그대로 유지.
- 태그(`{I숫자}`, `{G0}`, `{/G0}`)는 개수·위치 그대로.
- 줄바꿈(\n) 구조는 유지. 폭이 넘치면 줄바꿈 위치만 조정한다.
- 의미 추가·삭제 금지.
