글자 간격·굵기와 번역 말투를 다듬은 완성판입니다.

**원본 일본판 `data003.cpk`에 적용하는 전체 패치입니다.** 이전 버전을 먼저 적용할 필요가 없으며, 이미 한글 패치한 파일에는 덧씌울 수 없습니다.

## 변경 사항

### 글자

- 메뉴·대사의 한글이 서로 붙어 보이던 문제를 고쳤습니다. 글자 칸은 그대로 두고 한글만 조금 작게(88%) 그려 글자 사이에 틈을 만들었습니다.
- 굵은 제목 글자의 덧칠을 가로 방향으로만 주도록 바꿔 「통」「톱」「탈출」처럼 ㅌ·ㅂ·ㅊ이 뭉개지던 문제를 고쳤습니다.
- 작은 굵은 글자(「페이즈」·「합계」·「베스트」 등)의 덧칠을 빼서 원본 굵기에 맞췄습니다.
- 미션 제목에서 띄어쓰기가 사라지던 문제(「섹터α우주 영역」)를 고쳤습니다.
### 번역

- ライラット系 표기를 「라일라트계」로 바꿨습니다(「라일라트 전쟁」 포함).
- ボム를 「폭탄」으로 바꿨습니다.
- 폭스의 군대식 어미(「방심 마라!」 등)를 용병단 리더 말투로 풀었고, 팔코·빌·페피의 딱딱한 어미도 다듬었습니다.
- 「奴」를 「놈」 대신 「녀석」으로 옮겼습니다. 「놈」은 「貴様」처럼 원문이 대놓고 깔보는 곳에만 씁니다.
- 무전 보고문과 감탄사·호칭으로 끝나는 대사에 마침표를 넣고, 비명·웃음 대사에서는 마침표를 뺐습니다. 로봇 보고는 「분석 중. 분석 중.」처럼 문장마다 나눴습니다.
- 플레이 검수에서 찾은 어색한 표현을 고쳤습니다(「페퍼 장군에게서 긴급 통신!」, 「다음엔 두고 보자~!」 등).

## 적용 방법

1. `StarFoxZero_KO_v1.2f.zip`을 받아 압축을 풉니다.
2. 본인이 덤프한 일본판 원본 `data003.cpk`를 `패치하기.bat` 옆에 두고 `패치하기.bat`를 실행하면 `out\data003.cpk`가 만들어집니다.
3. 실기(Aroma + SDCafiine)는 `wiiu/sdcafiine/00050000101AFF00/StarFoxZero_KR/content/data003.cpk`를, Cemu는 기존 한국어 그래픽 팩의 `content/data003.cpk`를 새 파일로 교체합니다.
4. 패처가 원본과 결과를 자동으로 검사합니다. 직접 확인하려면 결과 파일의 확인값을 아래 표와 비교합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
