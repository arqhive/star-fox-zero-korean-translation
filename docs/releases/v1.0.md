플레이 검수를 반영한 정식 버전입니다. 번역 143곳을 고쳤으며, 타이틀 로고와 엔딩 청구서 이미지는 v0.9와 같습니다.

**원본 일본판 `data003.cpk`에 적용하는 전체 패치입니다.** 이전 한글 패치 파일에 덧씌울 수 없습니다.

## 변경 사항

- 플레이하며 검수한 번역 수정 143곳을 반영했습니다(표현 다듬기, 조사·띄어쓰기, 용어 통일).
- 반영 뒤 화면 폭을 넘긴 15곳을 뜻을 유지한 채 조정했습니다.
- 조작 안내의 "튕기기"를 "튕김"으로 한 글자 줄였습니다.
- 오른쪽 스틱 안내, 지원 물자·작전 중지 안내는 줄바꿈 위치를 다시 잡았습니다.
- 사운드 테스트 곡명 "섹터 α 우주 영역: 살바도라 내부"를 "섹터 α 영역: 살바도라 내부"로 줄였습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `StarFoxZero_KO_v1.0.zip` | 원본 일본판 `data003.cpk` | 패처(`패치하기.bat`)와 임베디드 Python, 사용자 설명서. |

## 적용 방법

1. `StarFoxZero_KO_v1.0.zip`을 받아 압축을 풉니다.
2. 본인이 덤프한 일본판 `data003.cpk`를 `패치하기.bat` 옆에 두고 `패치하기.bat`를 실행합니다. 20초에서 1분 정도 지나면 `out\data003.cpk`가 만들어집니다.
3. 만들어진 파일을 실기(Aroma + SDCafiine)는 `sd:\wiiu\sdcafiine\00050000101AFF00\StarFoxZero_KR\content\data003.cpk`에, Cemu는 그래픽 팩 폴더의 `content\data003.cpk`(`titleIds = 00050000101AFF00`)에 넣습니다.
4. 패처가 원본과 결과를 자동으로 검사합니다. 직접 확인하려면 결과 파일의 확인값을 아래 표와 비교합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
