타이틀 로고와 엔딩 청구서의 그래픽을 다듬은 업데이트입니다. 대사·메뉴 번역과 메시지 폰트 데이터는 v1.0과 같습니다.

**원본 일본판 `data003.cpk`에 적용하는 전체 패치입니다.** v1.0을 먼저 적용할 필요가 없으며, 이미 한글 패치한 파일에는 덧씌울 수 없습니다.

## 변경 사항

- 엔딩 청구서 손글씨의 실제 높이를 측정해 지정 영역 안에 배치했습니다. "안돌프"가 초록색 구분선에 겹치던 문제와 하단 서명이 세로로 지나치게 커지던 문제를 고쳤습니다.
- 청구서 제목에 원본의 녹색 명암 변화를 복원했습니다.
- 타이틀의 한글 보조 로고를 조금 키우고 중앙 정렬 오차를 고쳤습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `StarFoxZero_KO_v1.1.zip` | 원본 일본판 `data003.cpk` | 패처(`패치하기.bat`)와 임베디드 Python, 사용자 설명서. |

## 적용 방법

1. `StarFoxZero_KO_v1.1.zip`을 받아 압축을 풉니다.
2. 본인이 덤프한 일본판 원본 `data003.cpk`를 `패치하기.bat` 옆에 두고 `패치하기.bat`를 실행하면 `out\data003.cpk`가 만들어집니다.
3. 실기(Aroma + SDCafiine)는 `wiiu/sdcafiine/00050000101AFF00/StarFoxZero_KR/content/data003.cpk`를, Cemu는 기존 한국어 그래픽 팩의 `content/data003.cpk`를 새 파일로 교체합니다.
4. 패처가 원본과 결과를 자동으로 검사합니다. 직접 확인하려면 결과 파일의 확인값을 아래 표와 비교합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
