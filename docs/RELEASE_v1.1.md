타이틀 로고와 엔딩 청구서의 그래픽을 다듬은 업데이트입니다. 대사·메뉴 번역과 메시지 폰트 데이터는 v1.0 그대로 유지합니다.

## 변경 사항

- 엔딩 청구서 손글씨의 실제 높이를 측정해 지정 영역 안에 배치합니다. ‘안돌프’가 초록색 구분선에 겹치던 문제와 하단 서명이 세로로 지나치게 커지던 문제를 수정했습니다.
- 청구서 제목에 원본의 녹색 명암 변화를 복원했습니다.
- 타이틀의 한글 보조 로고를 조금 키우고 중앙 정렬 오차를 수정했습니다.

## 적용 방법

1. `StarFoxZero_KO_v1.1.zip`을 받아 압축을 풉니다.
2. 본인이 덤프한 **일본판 원본** `data003.cpk`를 `패치하기.bat` 옆에 둡니다.
3. `패치하기.bat`를 실행하면 `out/data003.cpk`가 만들어집니다.
4. 기존 한국어 패치의 `content/data003.cpk`를 새 파일로 교체합니다.

v1.0을 먼저 적용할 필요가 없는 전체 패치입니다. 이미 한글 패치된 CPK가 아닌 원본을 입력해야 합니다. Python이 포함되어 있어 별도 설치가 필요 없습니다.

- Wii U / SDCafiine: `wiiu/sdcafiine/00050000101AFF00/StarFoxZero_KR/content/data003.cpk`
- Cemu: 기존 한국어 그래픽 팩의 `content/data003.cpk`

배포 ZIP에는 게임 CPK를 포함하지 않습니다.

- 원본 CPK에 배포용 패처를 적용해 생성한 결과의 해시 일치 확인.

- 텍스처 압축·디코딩 결과, 손글씨 영역과 구분선 보존, 배포 ZIP 무결성 확인.
