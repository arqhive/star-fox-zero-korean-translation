# 그래픽 개선판 v1.1

기존 한국어 패치의 대사·메뉴·메시지 폰트는 유지하고 두 이미지 텍스처만 개선한다.

- 엔딩 청구서: 손글씨를 실제 문구의 잉크 높이로 측정하고 원래 영역 안에 맞춘다. `안돌프`가 위쪽 초록 구분선에 걸리던 문제와 서명이 세로로 커지던 문제를 수정했다.
- 청구서 제목: 원본 녹색 잉크의 행별 색상값을 추출해 한국어 글씨에 적용했다.
- 타이틀: 한글 보조 로고의 높이를 22px에서 25px로 조정하고, 실제 배치 폭으로 중앙 정렬한다. 기존 기울기와 글자 가로 비례는 유지한다.

## 결과 파일

- `out/graphics_v1.1/data003.cpk`: 바로 사용할 수 있는 개선판 CPK.
- `release/StarFoxZero_KO_v1.1.zip`: 원본 일본판 CPK에 적용하는 독립 배포용 패처. v1.0 패치를 먼저 적용할 필요가 없다.

## 재생성

저장소 루트에서 다음과 같이 실행한다. 원본 추출 데이터, v1.0 완성 CPK, v1.0 payload가 든 release 폴더, 임베디드 Python이 필요하다. v1.0 파일은 더 이상 보관하지 않으므로 `v1.0` 태그에서 다시 빌드해 준비한다.

```powershell
python tools/build_graphics.py --base <v1.0 data003.cpk> --release-base <v1.0 release 폴더> --original-dir work/orig
```

원본 추출 데이터가 저장소 바깥에 있다면 `--original-dir`로 그 경로를 지정한다. 출력 폴더가 이미 있으면 덮어쓰지 않고 중단한다. 재생성 시에는 `--output`과 `--release-output`에 새 경로를 지정하며, ZIP도 기존 파일과 충돌하지 않도록 다른 부모 폴더를 사용한다.

빌더는 v1.0 manifest로 입력 CPK를 확인하고, 원본 텍스처에서 두 이미지를 다시 생성한다. 기존 CPK를 복사한 뒤 크기가 같은 WTP 두 개만 교체하므로 메시지 데이터와 아카이브 배치를 유지한다. 배포본은 기존 payload의 두 그래픽 delta와 결과 해시만 갱신한다.

## 검증

- 생성 WTP 디코딩 결과와 예상 이미지 일치.
- 타이틀·청구서 각각 수정 대상 텍스처 밖의 WTP 데이터 일치.
- CPK 전체에서 두 WTP 영역 밖의 바이트 일치.
- 배포용 delta를 원본 WTP에 적용한 결과와 생성 WTP 일치.
- 손글씨 네 영역의 높이·위치 검사 및 청구서 초록 구분선 픽셀 보존 확인.
- 배포 패처를 일본판 원본 CPK에 실제 적용하여 생성한 파일이 개선판 MD5와 일치함을 확인.
- 배포 ZIP의 전체 CRC 검사 통과. 기존 payload와 비교해 두 그래픽 delta만 변경됨을 확인.

MD5: `8e5ec4d4e4abe41dbb2a16aa456bbe6c`.
SHA-1: `5c6f88d641b52ebded3d3fd2a56d28eed03d4413`.
